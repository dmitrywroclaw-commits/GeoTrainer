# Страны на карте — полный базовый каталог

Расширение от 2026-11-04, после принятия пользователем пяти эталонных карточек из `10_GEOGRAPHY_PILOTS.md`.

## Объём

195 стран основного реестра: 193 члена ООН и два государства-наблюдателя, Святой Престол и Государство Палестина. Зависимые территории и частично признанные государства не добавляются как отдельные карточки базового реестра. На контекстной карте они могут быть подписаны согласно картографическому источнику.

Для каждой страны есть:

- стабильный `outline-<countryId>` (ID первых пяти карточек и десяти вопросов сохранены);
- силуэт без подписей и обзорная карта с соседними территориями и водоёмами;
- индивидуальная подсказка для узнавания формы, регион, источники, права и область показа;
- вопросы `identify` и `select-outline`, всего 390;
- поддержка смешанного квиза, объяснений, ошибок и локального прогресса.

Водная тема остаётся из пяти карточек и 18 вопросов. Общий каталог географии содержит 200 карточек и 408 вопросов.

## Источники и сборка

Основа — уже закреплённый Natural Earth Admin 0 1:10m, commit `ca96624a56bd078437bca8184e78163e5039ad19`, SHA-256 `239eec57ac17f100a11e2536cffc56752c318b50ae765b0918ff7aab4ce8f255`. Подписи морей — Natural Earth Marine Areas из того же commit, SHA-256 `53f865e8ffa966cdd402145c82c5cd14ee7ce974cd0eb9a3f59f03a4cfd2d66c`. Оба набора public domain; ссылки, автор и атрибуция находятся в данных и карточках. Коды и региональный реестр соотносятся с UN M49; названия стран переиспользуются из существующего базового каталога.

`content/research/outline-cues.json` содержит индивидуальные редакционные подсказки по всем 195 силуэтам. Это описания видимой формы, не утверждения о символике или политическом статусе.

`scripts/expand-outline-catalog.py` создаёт структурированные записи и географически привязанные подписи в `content/geography.json`, а также отчёт покрытия `content/research/outline-coverage.json`. Генератор проверяет, что подсказки покрывают весь реестр. Данные не создаются нейросетью во время работы приложения.

`scripts/outline_geometry.py` читает источники с проверкой SHA-256, обрабатывает геометрию, перенос долгот и ограничение показа. `scripts/generate-geography-maps.py` выпускает 390 SVG и отчёт `content/research/outline-map-audit.json`. Геометрия обрезается по рамкам, упрощается в экранных координатах с сохранением топологии; мелкие острова не заменяются увеличенными участками суши. Для очень маленьких островов используются незакрашенные кольца-указатели.

Для воспроизведения:

```text
python -m pip install --target artifacts/geography-tools shapely==2.1.2
python -X utf8 scripts/expand-outline-catalog.py
python -X utf8 scripts/generate-geography-maps.py
```

Shapely — только инструмент подготовки контента. В приложение и его зависимости времени выполнения он не входит. Исходные GeoJSON кэшируются локально, а SVG включаются в статическую поставку.

## Особые случаи

- США: основная часть, Аляска и Гавайи — три врезки с собственными масштабами.
- Испания, Португалия, Эквадор, Экваториальная Гвинея и Йемен: отдельные врезки для удалённых частей.
- Кирибати, Микронезия, Маршалловы Острова, Тувалу, Сейшелы, Мальдивы, Палау и Тонга: общий рисунок и увеличенные фрагменты.
- Россия, Фиджи и другие тихоокеанские государства: долготы переносятся в локальное окно без разрыва у 180°; в схеме допустимы долготы за пределами ±180° для непрерывного окна.
- Франция, Дания, Норвегия, Великобритания, Нидерланды, Австралия, Новая Зеландия, Маврикий и Чили: область показа явно описана; исключённые удалённые территории не выдаются за полный силуэт всех владений.
- Кипр: для узнавания показывается остров целиком, с явным пояснением об административном разделении. Сомали: общий контур включает Сомалиленд, без утверждения о едином контроле. Для спорных границ приводится примечание к версии источника. Эти карты не являются картами текущего контроля.
- Святой Престол, Монако и другие микрогосударства: геометрия отдельно масштабируется для вопроса, на обзорной карте при необходимости применяется указатель.

Все виды ориентированы севером вверх. Врезки не сохраняют общий масштаб и расстояния между частями; это явно обозначено. Отдельные зависимые территории не объединяются с материнской страной без описанной области показа.

## Интерфейс и производительность

В каталоге есть поиск по названию, региону и подсказке, фильтр по пяти крупным регионам и выдача по 24 карточки с кнопкой «Показать ещё». Фильтр или новый поиск сбрасывает число показанных карточек. Дистракторы предпочитают тот же регион и похожую форму; в вопрос с выбором силуэта включаются только четыре нужных изображения.

Медиа загружаются лениво и кэшируются после просмотра существующим PWA-механизмом. Все 390 SVG заранее не загружаются. Существующие прогресс, маршруты и четыре основных раздела навигации сохранены.

## Проверки

Типизация, unit и production build обязательны. Unit сверяет покрытие 195/195, коды стран, уникальность ID, источники, наличие всех 390 SVG, все ответы, непрерывные долготы, врезки, ошибочные данные и повторение. Playwright проверяет фильтры/поиск/порционную выдачу, сложные карты, правильный/неправильный ответы, объяснение, клавиатуру, сохранение прогресса, офлайн и обязательные ширины. Контактные листы всех силуэтов и сложных обзорных карт сохраняются для визуальной проверки.
