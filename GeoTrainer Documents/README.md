# GeoTrainer — Development Documents

This folder contains the initial product and engineering specification for the GeoTrainer PWA prototype.

## Documents

- `01_CONCEPT.md` — product concept, scope, principles, MVP and non-goals.
- `02_PROTOTYPE_DESIGN.md` — UI, routes, architecture, responsive behavior, PWA and testing requirements.
- `03_CONTENT_MODEL.md` — structured content schemas, source policy and media-rights metadata.
- `04_DEVELOPMENT_PLAN.md` — implementation phases, milestones and definition of done.
- `AGENTS.md` — repository-level instructions intended for Codex/AI coding agents.

## Recommended starting sequence

1. Read `01_CONCEPT.md`.
2. Read `02_PROTOTYPE_DESIGN.md`.
3. Implement repository skeleton according to `04_DEVELOPMENT_PLAN.md`.
4. Define types and validation from `03_CONTENT_MODEL.md`.
5. Create five golden sample records before bulk content work.

## Working name

**GeoTrainer**

The name is intentionally descriptive: the product is a geography training tool, not only a quiz and not only an encyclopedia.
