# Этап «Столицы»: карточки и квиз

План обновлён 2026-09-26 по решению пользователя: учебная цель — запомнить пару **страна ↔ столица**. Исходный `geotrainer_capitals_cards.md` содержит 195 стран. Это список кандидатов для проверки фактов, а не инструкции по реализации и не источник прав на изображения.

## 1. Текстовые карточки и квиз

1. Сопоставить 195 стран со стабильными ID каталога. Проверить роли городов по авторитетным источникам; сохранить ссылку, издателя и дату проверки в структурированных данных.
2. Создать карточки всех городов и столичных функций без обязательной фотографии. Для стран с разделёнными функциями предусмотреть несколько карточек. Для Науру не приписывать Ярену статус официальной столицы; для спорных и недавних изменений дать точную формулировку.
3. Показывать в Learn город, страну, роль, научно-популярное описание и источники. В описании давать конкретный факт о географии, истории или значении города; численность населения указывать только с датой и источником. Поиск работает по городу и стране.
4. Генерировать из карточек вопросы **страна → столица** и **столица → страна**. Когда у страны несколько столиц или есть спорная роль, указывать её в вопросе. Вопросов «что на фото?» не создавать. После ответа показывать объяснение и ждать явного перехода дальше.
5. Сохранять прогресс и ошибки через существующую локальную абстракцию IndexedDB. Использовать стабильные ID вопросов; добавление фотографий не меняет прогресс.

Локальный результат: 203 карточки для 195 стран и 404 текстовых вопроса. Описания всех городов отредактированы по отдельности; исследовательская таблица и источники сохранены в `content/research/`.

## 2. Фотографии городов

1. Для каждой карточки подобрать известный городской вид или узнаваемое место **именно этого города**. Не требовать одного памятника для каждого города: панорама или характерная улица подходят, если они помогают связать название с обликом места. Фотография служит дополнением к карточке и не раскрывает ответ в квизе, поскольку квиз остаётся текстовым.
2. Для каждого файла проверить город и изображённое место, страницу исходного файла, автора, лицензию, ссылку на условия и требуемую атрибуцию. Официальный сайт или поисковая выдача сами по себе не дают права на публикацию.
3. Сохранять пригодное изображение локально в `public/media/capitals/` и записывать метаданные в реестр столиц. Показывать подпись и атрибуцию на карточке. Не предзагружать всю медиатеку в PWA; кэшировать просмотренные изображения и ясно показывать недоступность непросмотренного фото офлайн.
4. Если для города пока нет подходящего файла с проверенными правами, сохранять готовую текстовую карточку и отмечать пробел в отчёте покрытия. Не публиковать неподтверждённое изображение ради формального заполнения.

Локальный результат: 203/203 карточек с фотографиями и метаданными источника, автора и лицензии; текстовые вопросы не зависят от фото.

## 3. Локальная проверка и пользовательский гейт

1. Проверить покрытие 195/195 стран, источники каждой опубликованной карточки, уникальность ID, однозначность вариантов ответа, наличие медиафайлов и их правовых метаданных.
2. Запустить `npm run typecheck`, `npm test`, `npm run build` и релевантные Playwright потоки. Проверить ширины 360, 390, 430, 1280 и 1440 px, Learn → карточка → вопрос, ошибочный ответ → Mistakes, сохранение прогресса и офлайн-оболочку.
3. Показать пользователю локальный предпросмотр, число карточек и фотографий, спорные столичные роли, результаты проверок и состав изменений. Получить явное согласие пользователя после локального тестирования.
4. Только после согласия проверить staged diff, сделать коммит в ветке `codex/capitals-cards` и отправить его в GitHub. Не включать посторонние файлы и черновики из основной рабочей папки.
