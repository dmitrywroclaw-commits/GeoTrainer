# Карточки столиц мира для GeoTrainer

Рабочий документ для проектирования обучающих карточек по столицам.

## Охват

- **195 карточек**: 193 государства-члена ООН + 2 государства-наблюдателя.
- Для каждой карточки указаны:
  - столица;
  - почему этот город является столицей или какую столичную функцию он выполняет;
  - узнаваемый символ;
  - идея основной иллюстрации.

## Как должна выглядеть карточка

1. **Крупно:** название столицы.
2. **Подзаголовок:** «столица [страны]».
3. **Короткий факт:** почему город важен / почему он столица.
4. **Символ:** самый узнаваемый объект города.
5. **Иллюстрация:** открыточный или знаковый вид, который помогает запомнить столицу.

## Важные оговорки для разработки

- **Боливия** — Сукре является конституционной столицей, а Ла-Пас — местом правительства.
- **Нидерланды** — Амстердам является столицей, но правительство и парламент находятся в Гааге.
- **ЮАР** — три столицы: Претория (исполнительная), Кейптаун (законодательная), Блумфонтейн (судебная).
- **Шри-Ланка** — Шри-Джаяварденепура-Котте официальная законодательная столица, Коломбо остаётся крупнейшим деловым и административным центром.
- **Эсватини** — Мбабане административная столица, Лобамба законодательная и королевская.
- **Науру** — официальной столицы нет; фактический административный центр — Ярен.
- **Палестина** — в карточке нужно аккуратно отметить заявленную столицу и фактический административный центр.

## Идеи для механики запоминания

### Базовые режимы
- **Картинка → город**: по фото символа нужно вспомнить название столицы.
- **Город → страна**: по названию столицы определить государство.
- **Страна → столица**: классический режим.
- **Символ → столица**: отдельный продвинутый режим.

### Как усилить запоминание
- Использовать **один главный символ**, а не случайную панораму.
- На карточках-ловушках добавлять подпись **«не путать с…»**.
- Особенно полезны карточки для таких пар:
  - Анкара ≠ Стамбул
  - Канберра ≠ Сидней
  - Оттава ≠ Торонто
  - Бразилиа ≠ Рио-де-Жанейро
  - Додома ≠ Дар-эс-Салам
  - Ямусукро ≠ Абиджан
  - Амстердам ≠ Гаага
  - Сукре / Ла-Пас
