# Исследовательские реестры GeoTrainer

Эти CSV — редакционная рабочая зона. Наличие строки здесь не публикует карточку в приложении. Публикация происходит только после проверки источников, прав на конкретное изображение и переноса прошедшей редактуру записи в `content/library.json` и `content/media.json`.

Текущие счётчики пакетов, очередь сомнений и незакрытые проверки ведутся в `PROGRESS.md`.

## Файлы

- `countries.csv` — зафиксированный список 193 членов ООН и двух государств-наблюдателей с кодами UN M49/ISO.
- `flag-variants.csv` — один официальный вариант флага или строка итогового решения об отсутствии подходящего варианта.
- `emblems.csv` — официальный герб, эмблема или печать либо итоговое отрицательное решение.
- `landmark-candidates.csv` — конкретные природные объекты; охраняемая территория и расположенный в ней объект не считаются автоматически одной сущностью.
- `nature-source-catalog.csv` — полный датированный обход исходных natural/mixed записей всемирного наследия и глобальных геопарков ЮНЕСКО; строки остаются `deferred`, пока из них не выделен конкретный физический кандидат.
- `sources.csv` — источники фактов и утверждений.
- `media-review.csv` — права и атрибуция для каждого конкретного файла.

Списки в нескольких полях разделяются символом `|`. Координаты записываются как `широта;долгота`. Пустое поле означает «не исследовано» и не должно трактоваться как отсутствие факта.

`unesco-whc-source-catalog.json` — машинный снимок официальных natural/mixed списков, из которого воспроизводимо строится CSV. Он не является публикационным контентом приложения.

## Проверка

```sh
npm run research:validate
```

Первичное создание реестров выполняет `scripts/research/seed-research.mjs`. По умолчанию скрипт загружает официальные страницы ООН. Существующие CSV он не перезаписывает; явный `--force` предназначен только для осознанного пересоздания до начала ручной редакторской работы.

Проверенные пакеты стран хранятся в `content/research/batches/`. Применение нового пакета к реестрам выполняется командой:

```sh
node scripts/research/apply-country-batch.mjs content/research/batches/<batch>.json
```

Скрипт не заменяет существующие решения и источники с тем же ID: повтор или конфликт завершается ошибкой, чтобы редактор сначала осознанно разобрал расхождение.

## Решение по схеме приложения

UN M49 и ISO-коды страны, а также `isPrimaryStudyVariant` хранятся в боевом контенте. Координаты, измерения с методикой и утверждения о рекордах поддерживаются как опциональные структурированные поля природной карточки. Исследовательские статусы, причины исключения, очередь сомнений и альтернативные медиа остаются в CSV и не увеличивают загружаемый приложением JSON.
